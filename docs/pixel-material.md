# 像素材质画法：用代码按像素画师的方法逐格上色

> 用在背景场景和道具上，目标是「约 90% 拟物」：桌子像桌子、手机像手机、报告单像真的报告单。
> 代码：`pix.py`（画法本身）、`px_parts.py`（场景零件库：房间、地板、墙纸、窗、窗帘、书架、盆栽、挂钟、门、桌子、想象云……）、`px_demo.py`（样张：夜里的房间一角 + 书桌，照着它写新场景）。
> 来源：我做过最好的一期像素动画的背景画法（2026-10 定稿）。

---

## 一句话说明

画面全部由 Python 代码画出，没有用 AI 出图。代码把画面当成一张格子纸，**一格一格决定每个小方块填什么颜色**，规则模仿像素画师手绘时的习惯：

- 有限的色阶
- 按体积分出亮面和暗面
- 材质纹理
- 选择性描边
- 投影

## 为什么要换成这套画法

以前的画法是用代码画一大块一块的平面形状（矩形、多边形、椭圆），每块只有两三个颜色。轮廓虽然对，但看起来像矢量图，简单、不精致。

真正的像素画精致在**每一格的颜色都是有意安排的**：哪里亮、哪里暗、哪里有木纹、哪里有反光、东西底下有没有影子。这套画法就是把这些安排写成规则，让代码自动做。

---

## 第一步：把画面当成格子纸

- 整个画面 1920×1080，切成 **4×4 像素一格**，大约 480×270 格。
- **每一格只能填一种颜色**，像素画"一颗颗方块"的质感就是这么来的。
- 坐标用画面上的像素位置（世界坐标），代码自动换算成第几格。

## 第二步：圈出每样东西占哪些格子（形状）

只决定"哪些格子属于这个东西"，还不上色。三种基本形状：

| 形状 | 用法 | 例子 |
|---|---|---|
| `rect(x0, y0, x1, y1)` | 长方形 | 一块砖、一块木板、吧台台面 |
| `ell(cx, cy, rx, ry)` | 椭圆 | 杯口、叶子、灯泡、钟面 |
| `poly([(x, y), ...])` | 任意多边形 | 灯罩、窗外的遮阳棚、外套 |

## 第三步：逐格决定用哪个颜色

这一步是关键。以前是整块刷一种颜色，现在每一格单独判断，分 5 个环节。

### 1. 色阶：每种材质 5 级颜色，暗部偏冷、亮部偏暖

从一个"本色"自动生成 5 个颜色：

| 级别 | 0 最暗 | 1 暗 | 2 本色 | 3 亮 | 4 高光 |
|---|---|---|---|---|---|
| 怎么来 | 压暗到约 62%，混 22% 冷紫色 | 介于两者之间 | 原来的颜色 | 介于两者之间 | 提亮到约 122%，混 25% 暖黄色 |

- 冷紫色是 (58, 46, 96)，暖黄色是 (255, 236, 190)。
- 这叫**色相偏移**：暗部往冷色偏，亮部往暖色偏。只加黑、加白，颜色会发灰发脏；偏一点色相，颜色才有层次、看着"活"。
- 代码：`pix.ramp(本色)`。

### 2. 体积：按形状分出亮面和暗面

默认光从左上方来。不同形状的分层规则不一样，**分层是一块一块的，不用渐变，也不撒噪点**。

**方块（box）**：砖、木板、柜子、台面、书。

```
4 4 4 4 4 4 3    ← 最上面一格：高光
3 2 2 2 2 2 1    ← 上面第二格：亮
3 2 2 2 2 2 1    ← 中间：本色（最左一格亮一级）
3 1 1 1 1 1 1    ← 靠下两格：暗（最右两格也暗）
0 0 0 0 0 0 0    ← 最下面一圈：描边（见下文）
```

- 顶边亮几格、底边和右边暗几格，可以调（参数 `bands`）。小东西用 (1, 1)，大东西用 (2, 2)。

**圆（round）**：杯子、叶子、灯泡、钟、球。

- 在左上偏里的位置放一个"亮点"，按每格离亮点有多远，一圈一圈降级：最中心是 4 级高光，往外依次是 3、2、1。
- 离亮点很近的一小块强制用高光，形成一个反光点。

**竖圆柱（cylv）**：罐子、凳子腿、灯罩、雨伞桶、外套。

- 偏左有一道窄窄的竖向高光（4 级），高光左边是亮面（3 级），中间本色，右边暗面（1 级）。

**横圆柱（cylh）**：横着的管道、灯罩的金属边、凳子的脚踏环。

- 同样的道理，换成上下方向：上面一道高光，下面暗。

**平面（flat）**：窗外的远景、黑板、屏幕这种不需要立体感的地方，只用本色，后面可以再叠材质纹理。

### 3. 材质：在体积分层上再叠一层有规律的纹理

纹理的做法是"在某些格子上升一级或降一级颜色"。**全部是有规律的图案，不是随机撒点**，所以不会变成噪点。

| 材质 | 规则 | 用在 |
|---|---|---|
| 木头 `wood` / 竖木纹 `woodv` | 每隔约 5 行有一条弯弯的木纹（降一级），每隔约 11 行有一条断续的亮纹，按面积随机点几个木结 | 桌子、吧台、护墙板、木梁、相框 |
| 砖墙 | 每块砖单独当一个方块来画：颜色在本色上随机浮动 ±10%，每块都有自己的亮边、暗边和描边；砖之间露出砖缝；偶尔一块缺个角 | 后墙 |
| 金属 `metal` | 在宽度约 22% 的位置有一道很亮的竖条，32% 处再有一道细的 | 咖啡机、管道、灯罩、凳子腿、显示器 |
| 玻璃 `glass` | 每隔一段有几道斜着的反光条 | 窗户、豆子罐、蛋糕柜、小费罐 |
| 釉面 `ceramic` | 左上角有一小块很亮的反光 | 杯子、花盆 |
| 石头 `stone` | 用大片的明暗起伏做成不规则石纹 | 大理石台面 |
| 布 `fabric` | 一道道横向织纹，隔行有小点 | 椅垫（大面积不要用，会看成格子） |
| 纸 `paper` | 每隔几行一道浅线 | 纸张、单据 |

### 4. 选择性描边

- 物体**朝下、朝右**的那一圈边：用最暗的 0 级颜色描线。
- 物体**朝上、朝左**的那一圈边：反而提亮一级（边缘光）。

这样东西看起来立体、边缘清楚，又不会像卡通那样被一圈黑线框死。这是像素画常用的"选择性描边"。

### 5. 投影和接触阴影

- **投影**：把物体的形状往右下挪几格（比如 3 格、2 格），把那里**已经画好的东西压暗**（比如压暗 40%~55%）。物体自己不会被盖住。凳子在地上、货架在墙上、杯子在桌上，都有一块分明的影子。
- **接触阴影**：墙和地板交界、物体底边，往上或往下压暗 2~4 行，每行一层，越靠近交界越暗。东西才像"放在"地上，而不是飘着。

## 第四步：一层层叠起来，最后打光

**从后往前画，前面的东西自然挡住后面的**（咖啡馆的例子）：

1. 地板（透视方砖）、两侧墙、天花板
2. 后墙：红砖、木护墙板、墙脚阴影
3. 木梁、管道
4. 大窗：窗外街景、窗框、窗台绿植、遮阳棚
5. 黑板菜单、霓虹灯、挂画、挂钟、货架和罐子、吊灯
6. 后排客人（人物精灵）
7. 后排的桌子、衣帽架、雨伞桶、A 字招牌
8. 咖啡师（只露上半身）
9. 吧台：木板正面、大理石台面、咖啡机、磨豆机、收银机、蛋糕柜、高脚凳
10. 男主的椅背 → 男主 → 前面的桌子、杯子、盆栽、小狗
11. 整体打光
12. 想象泡泡、字幕

要让人物坐在桌子后面、站在吧台后面，就把桌子、吧台单独画成一层，放在人物之后画。

**最后整体打光**：只做柔和的明暗变化，把整个房间照亮。咖啡馆是三盏吊灯的暖光加窗户进来的冷光。

- 不用像素抖动（会出满屏的点）。
- 不做大圈光晕。
- 不能只亮一小块、其余全黑。

## 怎么用（代码示例）

```python
import pix as P

s = P.Scene()                                    # 一张新的格子纸（整个画面）

# 一块木桌面：方块体积 + 木纹 + 往右下投影
s.obj(s.rect(760, 770, 1240, 796), (120, 80, 54), "box", "wood", shadow=(0, 5, 0.45))

# 一个杯子：竖圆柱 + 釉面反光
s.obj(s.rect(1080, 728, 1120, 768), (240, 236, 226), "cylv", "ceramic")

# 一盏吊灯的灯罩：竖圆柱 + 金属高光
s.obj(s.poly([(952, 420), (1048, 420), (1022, 370), (978, 370)]), (40, 70, 66), "cylv", "metal")

# 墙脚压暗 4 行
s.band_ao(640, depth=4, k=0.3)

s.blit(fr)                                       # 画到这一帧上（跟着镜头推拉）
```

`s.obj(...)` 常用参数：

| 参数 | 意思 |
|---|---|
| 第 1 个 | 形状（`s.rect` / `s.ell` / `s.poly` 圈出来的格子） |
| 第 2 个 | 本色，例如 (120, 80, 54) |
| 第 3 个 | 体积：`"box"` 方块 / `"round"` 圆 / `"cylv"` 竖圆柱 / `"cylh"` 横圆柱 / `"flat"` 平面 |
| 第 4 个 | 材质：`"wood"` `"woodv"` `"metal"` `"glass"` `"ceramic"` `"stone"` `"fabric"` `"paper"`，不要纹理就不填 |
| `shadow=(右移格数, 下移格数, 压暗程度)` | 投影 |
| `outline=False` | 不描边（远景、屏幕里的东西） |
| `bands=(顶边亮几格, 底边右边暗几格)` | 方块的分层宽度 |

大球体（星球、大圆石）用 `s.sphere(cx, cy, r, 本色)`：按圆心和半径算每格亮度，球只露出一部分时也对。

**场景只画一次**：用 `@lru_cache` 包住 `build()`，每帧只 `build().blit(fr)`。所以只有第一帧慢（一个复杂房间要十几秒），后面很快。

**人物要坐在桌子后面、站在吧台后面**：把场景拆成两层，`build()` 画背景，另一个函数画桌子、吧台这些前景（`px_demo.py` 里叫 `build_desk()`）；每帧按「背景 → 人物 → 前景」的顺序贴（见 `px_demo.py`）。椅子、沙发同理：靠背在人物之前画，椅面前沿和椅腿在人物之后画。

**零件库 `px_parts.py` 常用的**：`room`（一点透视房间外壳）、`wood_floor` / `tile_floor`、`wallpaper`、`wainscot`（护墙板）、`baseboard`、`window`（带窗外小景）、`curtain` / `drape`、`books` / `bookcase`、`plant` / `pot`、`wall_clock` + `clock_hands`（指针可以动）、`rug`、`door`、`table`、`drawers`、`frame_pic`（挂画）、`pendant` / `ceiling_lamp`、`think_cloud` + `cloud_tail`（想象泡泡）、`speech_px`（对话气泡）、`brick_wall`、`leaves`、`tree` / `round_tree`、`city`（窗外楼群）。先用零件，零件没有的再自己用 `s.obj` 画。

## 人物是另一套方法

主角和路人是 `sprites.py` 里的**字符画**：每个字母代表一种颜色，一行行写出来，格子比背景大。背景精细、人物大格子，是这套风格的一部分。
表情不做固定套数：分镜里需要什么情绪（怒眉、哭、脸红、黑眼圈、冒汗……），就在 `sprites.py` 的 `EYES` / `MOUTH` 里加零件；脸型、发型、配色定了就不重画。

## 踩过的坑（别再犯）

1. **用大块平面形状凑东西**：每块两三个颜色，看起来像矢量图，简单、不精致。
2. **像素抖动铺满画面**：满屏规则小点、彩色噪点，一眼就看出是噪点。
3. **大圈光晕、只亮一小块其余全黑**：房间要整体照亮。
4. **画出让人误会的东西**：床尾的斜条纹毯被看成木板；门后挂的外套看不懂是什么；外套用布纹画成格子，看着像一栋楼；规则的竖条纹布被看成暖气片；东西上方的细竖线被看成吊绳。
5. **色相偏移方向反了**：亮部发粉、暗部发绿。应该是暗部偏冷紫、亮部偏暖黄。
6. **道具照抄参考图**：参考图只用来看精细程度，道具要原创设计。
7. **按区域整块压暗**：树荫、阴影的边缘要弯弯曲曲、分几级，不能是直边的深色长方块。
8. **坐着的人腿没接上、悬空**：腿从被椅面挡住的那条线直接接着往下画，鞋正好落在地上；人脚正下方别放拖鞋这类东西，会被看成他的脚。
9. **身体零件只露一条边**：手、脚要么整只露出来，要么整只藏起来，只露黑边加一行肤色会被看成别的东西。
10. **一排树一棵棵叠着画，树冠像透明的圆叠在一起**：先画全部树干，再把所有树冠并成一整块暗底（只描最外圈），叶子在整块上统一撒、按高度排明暗。
11. **比例不对**：人比星球还大、人挤到墙上。人和物的比例要对，同一个镜头里人物大小统一。

## 每批场景交付前自查

- [ ] 道具够多、分三层：墙上装饰 / 中景家具 / 前景小物，室内至少十几样，每样都有明暗和材质
- [ ] 整个房间都照亮，没有大光晕，没有噪点
- [ ] 人物姿势符合分镜：坐就画出座位并坐实，名牌、文字该有的都有
- [ ] 没有让人误会的东西
- [ ] 放大看过局部（人物的脚、手、和家具接触的地方）
